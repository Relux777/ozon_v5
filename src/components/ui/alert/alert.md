# Alert

Всплывающие уведомления («тосты»): «Адрес скопирован», «Не удалось скопировать» и т.п. Без библиотек.

- **Вид:** карточка «жидкое стекло» — размытие фона, блик по кромке, отсвет и тень цвета типа; углы-«суперэллипсы»
  там, где браузер их умеет. Иконка — круг с градиентом, крестик — в кольце-таймере.
- **Появление:** «капля» с иконкой падает от края экрана и пружинит, затем раскрывается в карточку; текст и крестик
  выезжают следом, знак в иконке дорисовывается, от иконки по стеклу расходится волна цвета. У ошибки знак «мотает
  головой», у предупреждения — покачивается.
- **Закрытие:** текст гаснет, карточка сворачивается обратно в «каплю» и исчезает; соседи пружиной занимают место.
- **Типы:** `success` (по умолчанию), `error`, `warning`, `info` — свой цвет и знак.
- **Позиции:** `top-right` (по умолчанию), `top-left`, `top-center`, `bottom-right`, `bottom-left`, `bottom-center`,
  `center`. Карточка раскрывается от «своего» края: справа — влево, слева — вправо, по центру — в обе стороны.
  На телефоне (≤620px) верхние и нижние — во всю ширину.
- **Стопка-«колода»:** несколько уведомлений в одном углу лежат друг на друге — переднее целиком, из-под него
  выглядывают ещё два (меньше и ниже). При наведении мыши или фокусе стопка раскрывается списком; на сенсорных экранах
  и при «уменьшении движения» — всегда раскрыта.
- **Сами пропадают** через `duration` (по умолчанию 4 с): кольцо вокруг крестика показывает, сколько осталось.
  Время стоит, пока уведомление читают или держат: наведение мыши, фокус с клавиатуры, палец на карточке, скрытая
  вкладка. `duration: 0` — висит, пока не закроют.
- **Закрыть** — крестиком, клавишей Esc (когда фокус в уведомлении) или свайпом вбок: далеко или коротким быстрым
  «смахом» (палец и мышь). Недотянутая карточка пружинит на место.
- **Действие:** необязательная кнопка в карточке (`action`) — «Отменить», «Открыть»; после нажатия уведомление закрывается.
- **Повтор:** с тем же `id` уведомление не дублируется — выходит вперёд, «подпрыгивает», перерисовывает знак и заново
  отсчитывает время.
- **Не больше `max` в одном углу** (по умолчанию 3) — лишние, самые старые, закрываются.
- **Поверх всего:** стопка рисуется в верхнем слое браузера (Popover API) — выше любых `z-index`, модальных `<dialog>`
  и полноэкранных окон. В браузере без Popover API — обычный `position: fixed` со слоем `--alert-z`.
- **Вибрация:** на телефоне (Android) — короткий отклик при появлении, у ошибки тройной. Отключается пропсом `haptics`.
- **Скринридеры:** текст уведомления объявляется через живые регионы (`role="status"`, для `error` — `role="alert"`),
  которые есть в DOM заранее. Закрыли с клавиатуры — фокус уходит на соседнее уведомление или туда, откуда пришёл.
- **Настройки системы:** «уменьшить движение» — без движения, только проявление, стопка раскрыта, таймер работает;
  «уменьшить прозрачность» и «повысить контраст» — сплошной фон вместо стекла; режим принудительных цветов — рамка.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.tsx` | `AlertProvider`, хук `useAlert`, стопка (`AlertStack`: верхний слой, замер высот, сдвиги) и карточка (жесты, закрытие) |
| `_alert.scss` | глобальные классы `.alert*`: стопки по углам, «колода» и раскрытый список, стекло, цвета типов, анимации |

## Что нужно в проекте

1. **Стили** — строка в начале `style.scss`:
   ```scss
   @use "../../components/ui/alert/alert";
   ```
2. **Провайдер** вокруг приложения (в Ozon V5 — `app/[locale]/layout.tsx`, внутри `NextIntlClientProvider`):
   ```tsx
   <AlertProvider>{children}</AlertProvider>
   ```
3. **Переводы** в разделе `A11y` (он должен быть в `clientMessages`): `alerts` («Уведомления» — подпись области),
   `alertClose` («Закрыть уведомление»). CopyCode/CopyLink берут оттуда же `copyFailed`.
4. ReluxCode: `flex nowrap align-center gap-12 overflow-hidden grid place-center br-round shrink-0 flex-1 gap-2
   hover-none sr-only`.

## Пример

```tsx
'use client';
import { useAlert } from '@/components/ui/alert';

const alert = useAlert();

alert.show({ title: 'Адрес скопирован', text: address });                 // success, сверху справа
alert.show({ type: 'error', title: 'Не удалось скопировать' });
alert.show({ type: 'info', title: 'Сохранено', position: 'bottom-center', duration: 6000 });
alert.show({ id: 'net', type: 'warning', title: 'Нет сети', duration: 0 }); // висит, пока не закроют
alert.show({ type: 'info', title: 'Город удалён', action: { label: 'Отменить', onClick: restore } });
const key = alert.show({ title: '…' });
alert.close(key);
```

Без `AlertProvider` выше по дереву `useAlert()` возвращает заглушку — вызовы ничего не делают, компонент не падает.

## Пропсы `AlertProvider`

| Проп | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `position` | `AlertPosition` | `'top-right'` | где показывать, если у уведомления не задано своё |
| `duration` | `number` (мс) | `4000` | сколько висит уведомление; `0` — пока не закроют |
| `max` | `number` | `3` | сколько уведомлений одновременно в одном углу |
| `haptics` | `boolean` | `true` | короткая вибрация при появлении уведомления на телефоне |

## Параметры `show()`

| Поле | Тип | Что делает |
|---|---|---|
| `title` | `string` | заголовок (обязательно) |
| `text` | `string` | вторая строка, не больше двух строк (адрес, код, ссылка) |
| `type` | `'success' \| 'error' \| 'warning' \| 'info'` | цвет и иконка |
| `duration` | `number` | своё время показа |
| `position` | `AlertPosition` | свой угол |
| `id` | `string` | ключ «того же самого» уведомления — повтор выводит его вперёд и обновляет, а не добавляет новое |
| `action` | `{ label: string; onClick: () => void }` | кнопка действия; после нажатия уведомление закрывается |

## Что менять под проект (в CSS проекта, на `:root`)

- `--alert-top` — отступ сверху: под фиксированной/липкой шапкой (в Ozon V5 — `calc(var(--header-h) + 10px)`).
- `--alert-bottom` — отступ снизу: над нижним меню (в Ozon V5 — как у `.float-btn`).
- `--alert-z` — слой для браузеров без Popover API (по умолчанию 50).
- Цвета типов — `--alert-accent` и `--alert-accent-2` (вторая точка градиента иконки) у `.alert-success/-error/-warning/-info`.
- «Колода»: сколько выглядывает и на сколько — `PEEK_COUNT`/`PEEK_PX` в `index.tsx` и `$peek` в `_alert.scss` (менять вместе),
  зазор раскрытого списка — `GAP_PX` и `$gap`.
- «Капля»: `PILL_PX` в `index.tsx` и `$icon`, `$pad` в `_alert.scss` (капля = иконка + два поля) — менять вместе.

## Как это сделано (и на что опирается)

| Что | Чем | Если браузер не умеет |
|---|---|---|
| пружины без библиотек | easing-функция `linear()` — заранее посчитанная кривая затухающего колебания (`$spring`, `$spring-bouncy`; в JS — `SPRING`) | `cubic-bezier` с небольшим перелётом (`@supports`) |
| раскрытие из «капли» | анимация `width` карточки; содержимое держит ширину стопки через `100cqw` (стопка — `container-type: inline-size`) и не переверстывается | — |
| поверх всего | Popover API: `popover="manual"` + `showPopover()` | `position: fixed` и `--alert-z` |
| углы-«суперэллипсы» | `corner-shape: squircle` | обычный `border-radius` |
| блик по кромке | градиент в полоске `padding` псевдоэлемента, середина вырезана `mask … exclude` | — |
| паузы таймера | кольцо — CSS-анимация, останавливается селекторами (`:hover`, `:focus-within`, `:has(.is-dragging)`, `.is-paused`) | — |
| закрытие, «подпрыгивание», возврат после свайпа | Web Animations API (`element.animate`) | — |

Таймер — CSS-анимация кольца: её `animationend` закрывает уведомление. Длительность кольцу задаётся в `style` с
`!important` — иначе общие сбросы «без анимации» (`* { animation-duration: 0.01ms !important }`, как в ReluxCode)
обнуляли таймер, и при включённом «уменьшении движения» уведомление закрывалось, не успев появиться.
