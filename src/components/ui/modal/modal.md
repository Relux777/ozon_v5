# Modal

Клиентская модалка: рендерится порталом в `#modal-root`, закрывается крестиком, кликом по фону, `Escape` и свайпом вниз
(на телефоне — как нижняя шторка iOS). При открытии блокирует прокрутку страницы, переносит фокус в диалог и возвращает
его на кнопку, которая её открыла.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.tsx` | компонент, логика свайпа и фокуса |
| `modal.module.scss` | анимации, позиции (`bottom`, `center`, `right`), ширины (`w_360px`, `w_440px`), мобильная версия |

## Что нужно в проекте

1. **Контейнер портала** — в корневом layout после контента:
   ```tsx
   <div id="modal-root"></div>
   ```
   Без него модалка ничего не рисует (тихо возвращает `null`).
2. **Иконка крестика** — `@/assets/svg/x.svg` (SVGR). Цвет задан прямо в разметке `fill="#679efe"` — поменять под бренд.
3. **Перевод** `A11y.close` (подпись крестика для скринридеров) и раздел `A11y` в `clientMessages`.
4. **ReluxCode**: используются `p-fixed`, `z-20`, `blur-7`, `bg-3-100`, `br-20`, `shadow-3`, `overflow-auto`, `visibility-hidden`,
   `active_scale_09` и др.

## Пропсы

| Проп | Тип | Обязательный | Что делает |
|---|---|---|---|
| `isOpen` | `boolean` | да | открыта ли модалка (состояние хранит родитель) |
| `onClose` | `() => void` | да | закрыть: родитель ставит `isOpen = false` |
| `ariaLabel` | `string` | да | название диалога для скринридеров |
| `position` | `'bottom' \| 'center' \| 'right'` | нет | где появляется панель (см. ниже) |
| `size` | `360 \| 440` | нет | ширина панели на экранах ≥500px |
| `className` | `string` | нет | дополнительные классы на подложку |
| `children` | `ReactNode` | да | содержимое |

Позиции:
- `bottom` — лист снизу, скругление только сверху;
- `center` — карточка по центру экрана (ручка свайпа скрыта);
- `right` — панель справа во всю высоту, 400px (оглавление, меню).

На экранах <500px любая позиция превращается в нижний лист со свайпом вниз.

## Пример

```tsx
'use client';

import { useState } from 'react';
import dynamic from 'next/dynamic';

// dynamic — код модалки не попадает в общий JS, пока её не открыли
const Modal = dynamic(() => import('@/components/ui/modal'));

export default function LanguageButton() {
    const [isOpen, setIsOpen] = useState(false);

    return (
        <>
            <button type="button" onClick={() => setIsOpen(true)} aria-haspopup="dialog">
                Язык
            </button>
            <Modal
                isOpen={isOpen}
                onClose={() => setIsOpen(false)}
                ariaLabel="Выберите язык"
                position="center"
                size={360}
            >
                <main className="pd-20">…содержимое…</main>
            </Modal>
        </>
    );
}
```

Тяжёлое содержимое (длинный список) лучше рендерить только после первого открытия — см. `LanguageSwitcher` в этом проекте
(`wasOpened` + предзагрузка чанка при наведении на кнопку).

## Что менять под проект

- **Цвет крестика** — `fill` у `<CloseIcon>` в `index.tsx`.
- **Новая ширина** — добавить модификатор в `modal.module.scss` по образцу `&.w_440px` и значение в тип `ModalSize`
  в `index.tsx`.
- **Новая позиция** — модификатор `&.имя` в `modal.module.scss` + значение в `ModalPosition`.
  Закрытое положение писать **только** через `&:not(.active) .content { transform: … }`: при равной специфичности
  с `.active .content` побеждает правило, которое ниже в файле, и модалка перестаёт выезжать (видно только затемнение).
- **Порог свайпа** — `SWIPE_THRESHOLD` (120px) в `index.tsx`; размытие фона — `MAX_BLUR` и класс `blur-7`.

## Подводные камни

- Свайп вниз не закрывает модалку, пока список внутри прокручен (`scrollTop > 0`) — это нормально: жест уходит на прокрутку.
- `z-20` у подложки: плавающие кнопки и нижнее меню проекта должны быть ниже или на том же уровне.
- На `next dev` Turbopack иногда не подхватывает новый класс в уже подключённом `modal.module.scss` — проверять на
  `next build` + `next start`, прежде чем чинить код.
- Проверять анимации на активной вкладке браузера: в скрытой переходы не идут, и `getComputedStyle` показывает закрытое положение.
