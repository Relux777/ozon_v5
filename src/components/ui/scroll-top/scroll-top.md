# ScrollTop

Клиентская круглая кнопка «наверх» в правом нижнем углу. Появляется после прокрутки на 400px (`SHOW_AFTER_Y`),
по клику плавно возвращает в начало страницы. Пока скрыта — не получает фокус (`tabIndex={-1}`).

Партиал `_scroll-top.scss` содержит и общий класс **`.float-btn`** (плавное появление/исчезновение) — им пользуются все
плавающие кнопки проекта, не только эта (в Ozon V5 ещё `PageNav`).

## Файлы

| Файл | Что внутри |
|---|---|
| `index.tsx` | компонент |
| `_scroll-top.scss` | `.float-btn`, `.float-btn-visible`, `.scroll-top-icon` (шеврон вниз, повёрнутый на 180°) |

## Что нужно в проекте

- `@use "../../components/ui/scroll-top/scroll-top";` в начале `style.scss`.
- Иконка `@/assets/svg/chevron-down.svg` (SVGR).
- Перевод `A11y.scrollTop` и раздел `A11y` в `clientMessages`.
- ReluxCode: `p-fixed z-20 grid place-center w-46 h-46 br-round bg-1-7 shadow-1 blur-7 active_scale_09 r-10 b-20`.

## Пример

```tsx
import ScrollTop from '@/components/ui/scroll-top';

// в конце страницы с длинным списком
<ScrollTop />
```

## Что менять под проект

- **Отступ над нижним меню.** Если в проекте есть фиксированное нижнее меню, кнопку нужно поднять над ним — это правило
  проекта, оно пишется в `style.scss` проекта, а не здесь. В Ozon V5:
  ```scss
  .float-btn {
      @media (width < 620px) { bottom: 98px; } // отступ меню + высота пункта + 12px
  }
  ```
- **z-index:** у кнопки `z-20`. Если обёртка нижнего меню на `z-10` и перекрывает нижнюю полосу экрана, кнопка с `z-10`
  перестанет нажиматься — любую новую фиксированную кнопку внизу ставить `z-20`.
- Порог появления — `SHOW_AFTER_Y`; позиция — классы `r-10 b-20` в разметке.
